# Дурак — помощник

Маленькое веб-приложение-компаньон для игры в дурак: отмечайте карты, которые уже вышли из игры, и сразу видно, какие ещё остались — по мастям и по козырю.

## Возможности

- **Отметка карт одним нажатием** — карта «ложится рубашкой вверх» и уходит из счёта; повторное нажатие возвращает её.
- **Бои (ходы)** — карты текущего боя помечены золотой точкой. Кончился бой:
  - **«В отбой»** — карты точно вышли из игры;
  - **«Взял»** — защитник забрал карты боя, и все они одним нажатием возвращаются в игру (отбой предыдущих боёв не трогается).
- **Козырь** — нажмите на масть в шапке колонки; козырная масть подсвечивается золотом.
- **Счёт** — сколько карт в игре и сброшено, отдельно по каждой масти.
- **Колода 36 или 52 карты** — переключается перед партией.
- **«Отменить»** — пошаговая отмена любого действия (карта, козырь, бой, «Взял»).
- **«Новая игра»** — в шапке, с подтверждением в два нажатия.
- **Офлайн и установка** — PWA: после первого открытия работает без интернета; можно добавить на домашний экран телефона.
- Состояние партии сохраняется между визитами.

## Как пользоваться

1. Откройте сайт, выберите размер колоды.
2. Нажмите на масть — станет козырём.
3. По ходу боя нажимайте на карты, вышедшие на стол.
4. Бой кончился отбоем — «В отбой»; защитник забрал карты — «Взял», и они вернутся в игру.
5. Ошиблись — «Отменить». Новая партия — «Новая игра» в шапке.

## Технологии

Статический сайт без сборки: HTML + CSS + ванильный JavaScript, сервис-воркер для офлайна, `localStorage` для состояния. Шрифты — PT Sans / PT Sans Narrow.

## Разработка

Любой статический сервер, например:

```sh
python3 -m http.server 8000
```

Кэш сервис-воркера версионируется константой `CACHE_VERSION` в `sw.js` — увеличьте её при изменении файлов.
